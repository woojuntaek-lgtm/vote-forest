# 다수결 숲

60점짜리 101개가 모이면 97.9점? — 분류 알고리즘과 앙상블을 손으로 체험하는 앱입니다. 지니 지수와 엔트로피, 선을 끌어 찾는 가장 깨끗한 질문(정보 획득량), 반달 데이터로 직접 키우는 의사결정나무와 깊이에 따른 과적합, 점을 끌어 보는 서포트 벡터 머신의 마진·서포트 벡터·소프트 마진과 C, z = x² + y²로 띄우는 커널 트릭, 정답률·모델 수·따라 하기를 바꾸는 다수결 실험실, 부트스트랩과 OOB, 랜덤 포레스트, 잔차를 이어 배우는 그라디언트 부스팅까지 담았습니다. 지능 07 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 나무: 사건 접수, 불순도 슬라이더, 퀴즈 ①(지니 0.32), 질문 고르기와 정보 획득량, 깊이와 과적합
- ② SVM: 끌어 보는 최대 마진과 C·섞여 든 점, 퀴즈 ②(C를 줄인다), 커널 트릭 3차원 보기
- ③ 앙상블: 다수결 실험실(독립 계산·4,000번 실험), 부트스트랩과 OOB, 나무 1그루 vs 숲 10·100그루
- ④ 부스팅: 잔차를 배우는 나무 더하기, 배깅 vs 부스팅, 모델 비교표와 코드, 세 줄 정리, 생각해 볼 질문
